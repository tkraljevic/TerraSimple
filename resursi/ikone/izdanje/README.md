# Ikone paketa

ICNS za macOS i ICO za Windows izvedeni su iz postojećih ikona TerraSimplea.
Za male prikaze koriste se `terrasimple-32.png` i `terrasimple-64.png`, a za
veće puni `terrasimple.png`. Crtež i odobreni stil nisu mijenjani.

Obnavljanje na Macu: `python3 skripte/ikone_izdanja.py`. Koriste se sustavni
`sips` i `iconutil`; ICO sadrži PNG prikaze od 32, 64 i 256 piksela.
